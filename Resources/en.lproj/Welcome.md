# Welcome to Markdown Viewer

Bring the focus back to reading.

Click **Open File** in the toolbar, or drop a `.md` file into the window. You can also choose “Open With → Markdown Viewer” in Finder.

## Reading Features

- Jump quickly between sections with the outline on the left
- **⌘F** to find, **⌘O** to open, **⌘R** to reload
- Adjust the font size and choose light, dark, or system appearance
- Tables, task lists, block quotes, and syntax highlighting
- Math formulas such as $E=mc^2$, and Mermaid diagrams
- Display local images from the same directory directly

## Code Example

```swift
struct Reading {
    let title = "Focused Reading"
    func open() { print(title) }
}
```
