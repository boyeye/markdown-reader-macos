# 欢迎使用 Markdown 查看器

让文字回到阅读本身。

点击工具栏的 **打开文件**，或把 `.md` 文件拖入窗口。也可以在 Finder 中选择「打开方式 → Markdown 查看器」。

## 阅读功能

- 左侧目录，快速跳转章节
- **⌘F** 查找、**⌘O** 打开、**⌘R** 重新载入
- 调整字号，切换浅色、深色或跟随系统
- 支持表格、任务列表、引用和代码高亮
- 支持数学公式，例如 $E=mc^2$，以及 Mermaid 图表
- 同目录的本地图片可直接显示

## 代码示例

```swift
struct Reading {
    let title = "专注阅读"
    func open() { print(title) }
}
```

## 表格

| 功能 | 状态 |
| --- | --- |
| 离线阅读 | 已支持 |
| 本地图片 | 已支持 |
| 数学公式与 Mermaid | 已支持 |
| 导出 PDF | 菜单「文件 → 导出 PDF」 |

> 文档只在本机处理。远程图片默认不加载，网页链接会在系统浏览器中打开。
